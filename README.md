# 中國象棋 · 平面棋盤

支援 **AI 第 1～20 級**與雙人對弈的中國象棋。一般玩家可使用 Windows 免安裝版，將單一 EXE 複製到其他電腦，雙擊即可離線遊玩；也保留瀏覽器網頁版。

棋盤固定為平面，紅方在下、黑方在上。棋子採用開源「霞鶩文楷 TC」中等字重，雙方文字正向顯示，並依實際筆畫範圍置中。

## Windows 免安裝版

適用於 Windows 10／11（x64、64 位元）。目前版本的檔名為 `ChineseChess-1.0.0-Windows-x64.exe`。

1. 取得已封裝的 EXE，或依下方[重新封裝步驟](#開發與重新封裝)自行產生。
2. 只複製這一個 EXE 到 USB 隨身碟或另一台電腦，不需攜帶原始碼和其他資料夾。
3. 雙擊 EXE，開啟棋盤後即可開始對弈；結束時直接關閉視窗。

**遊玩端不需要安裝 Node.js、Python 或字型，也不用另開伺服器。**遊戲、AI、Three.js、棋子字型與 Electron 執行環境均已封裝，對弈不需網路。程式啟動時會將必要檔案解壓到暫存目錄，首次啟動可能需要稍候；外部網站連結仍需網路。

> `release/` 是本機封裝輸出目錄，已由 `.gitignore` 排除。Git 儲存庫提供原始碼與封裝設定，`git clone` 或下載原始碼 ZIP 不會附帶 EXE。分享給玩家時，另外傳送已產生的 EXE 即可。

## 玩法

- 上方選單可選擇 **人機・第 1 級～第 20 級**或**雙人對弈**，預設為第 10 級。切換難度或模式會重新開局。
- 人機模式由玩家執紅先行，AI 執黑；思考時回合指示燈會閃爍。
- 點選己方棋子，再點目標交叉點走棋。綠點代表可走空位，紅圈代表可吃敵子；再點同一顆棋子可取消選取。
- 「悔棋」在雙人模式退一步，人機模式連同 AI 回應一起退回；「新對局」重新開始。
- 棋盤不會因拖曳或滾輪而旋轉、縮放，會依視窗大小自動完整顯示。
- 畫面包含最後一步標記、吃子托盤、傳統棋譜、將軍提示、勝負統計與戰績圖下載。
- 手機版將音效、全螢幕和玩法說明收進右上角「⋯」選單。

## AI 難度

可先從預設第 10 級開始，依對弈情況調低或調高。第 1 級最容易、第 20 級最難；這些級數是本程式的難度設定。

20 個等級各有搜尋設定：低級數保留較多隨機走法，高級數增加搜尋預算與深度，並縮小候選著法的分差範圍。以下列出部分級數，完整設定見 [difficulty.js](difficulty.js)。

| 級數 | 一般局面最大深度 | 每階段搜尋預算 | 隨機走法機率 | 候選著法分差 |
| --- | --- | --- | --- | --- |
| 1 | 1 層 | 0.12 秒 | 65% | 140 |
| 5 | 2 層 | 0.30 秒 | 28% | 70 |
| 10（預設） | 3 層 | 0.90 秒 | 0% | 8 |
| 15 | 4 層 | 2.40 秒 | 0% | 2 |
| 20 | 6 層 | 4.50 秒 | 0% | 0（最佳分數同分時隨機） |

低級數的隨機走法仍會遵守象棋規則。「候選著法分差」越小，越傾向選擇最佳著法。第 1～16 級可能另用一段搜尋預算確認接近最佳的候選；實際用時依局面與電腦效能而異，找到必殺時會提早返回。

第 10～16 級在少子殘局增加一層；第 17～20 級在少子殘局搜尋更深，最高可達 12 層。表中深度是搜尋上限，實際完成的深度會受時間預算及局面複雜度影響。

AI 在 Web Worker 中執行，保持畫面可操作；不支援 Worker 時使用主執行緒後備。引擎使用 negamax、alpha-beta 剪枝、靜態搜尋、將軍延伸、置換表與走法排序，並考慮近期重複局面。

## 象棋規則

- 支援馬腿、象眼、炮架、兵卒過河、九宮限制與白臉將規則。
- 將死或困斃判負。
- 同一局面（含輪走方）第三次出現時，若一方連續照將，該方以長將判負；否則判和。
- 以傳統棋譜記法記錄著法，例如「傌八進七」「炮二平五」。

## 執行網頁版

若要直接執行原始碼的網頁版，可在專案根目錄啟動靜態伺服器。例如，電腦已安裝 Python 時：

```bash
python -m http.server 8080
```

接著以瀏覽器開啟 <http://localhost:8080>。也可使用 `npx serve .` 或其他靜態伺服器。

網頁使用 ES module、importmap 與 Web Worker，需透過 HTTP 開啟，不能以雙擊 `index.html` 取代伺服器。Three.js 與棋子字型均由專案內的本地檔案載入，不依賴 CDN。停止網頁版時，在伺服器終端按 `Ctrl+C`。

## 開發與重新封裝

以下步驟供修改程式及製作 EXE 使用。請在 Windows 電腦準備 Node.js 22.12 或更新版本，並於專案根目錄執行。首次安裝套件及下載 Electron、封裝工具需要網路。

安裝開發套件：

```bash
npm ci
```

開啟桌面版預覽：

```bash
npm start
```

`npm start` 會先確認開發用 Electron 執行環境已備妥，再開啟遊戲視窗。

修改完成後，更新快取版本、執行測試並重新封裝：

```bash
node tools/bump-cache.mjs
npm test
npm run pack:win
```

封裝腳本會在系統暫存目錄建置，完成後將單一 EXE 複製至 `release/`，並輸出檔案大小及 SHA256。這樣可避免開發工具監看中間產物而造成檔案鎖定。

目前輸出為 `release/ChineseChess-1.0.0-Windows-x64.exe`，檔名版本取自 [package.json](package.json)。**修改原始碼不會自動更新既有 EXE**，分享新版前需重新封裝。

## 測試

```bash
npm test                      # 規則與 AI 測試，涵蓋第 1～20 級
node fuzz.mjs                 # 隨機對局模糊測試
node tools/bump-cache.mjs --check
```

## 部署與快取

此專案使用內容雜湊版本號，避免網頁更新後仍載入舊的 JS 或 CSS。修改後執行：

```bash
node tools/bump-cache.mjs
```

腳本會計算 CSS、遊戲模組及 `difficulty.js` 的內容，更新本地資源的 `?v=<hash>` 引用。同樣內容重複執行不會產生額外變更。

## 檔案結構

| 檔案或目錄 | 用途 |
| --- | --- |
| `index.html`、`css/style.css` | 網頁介面與響應式版面 |
| `main.js` | 棋盤呈現、互動、動畫與對弈流程 |
| `game.js` | 純邏輯規則引擎 |
| `difficulty.js` | 第 1～20 級共用設定 |
| `ai.js`、`ai-worker.js` | AI 搜尋引擎與 Worker |
| `desktop/` | Electron 視窗入口與 Windows 圖示 |
| `vendor/three/` | Three.js r160 模組與授權 |
| `fonts/` | 棋子字型子集、來源說明與 OFL 授權 |
| `package.json`、`package-lock.json` | 開發套件版本、執行指令與 Windows 封裝設定 |
| `tools/build-portable.mjs` | 暫存目錄建置、EXE 輸出與校驗值產生 |
| `tools/bump-cache.mjs` | 靜態資源版本號更新 |
| `release/` | 封裝產物，不納入 Git |
